2. Technical Overview
The system will be developed as a web-based AI application that accepts meeting transcripts, preprocesses the text, sends it to a Generative AI model, and generates structured meeting minutes. The system will also create embeddings of previous meeting records and store them in a vector database to support semantic search using RAG.

7. Database Requirements
7.1 Vector Database
Proposed options: FAISS or ChromaDB. Used to store embeddings of previous meeting records and support semantic search.
7.2 Metadata Database
Proposed options: SQLite or PostgreSQL. Used to store meeting metadata and structured information.
